# CareBridge HealthCare 🏥
> **Premier Medical Tourism & Super Specialty Healthcare Platform for Delhi NCR**

CareBridge HealthCare bridges international patients from across the globe (Middle East, Africa, CIS, Europe, Americas) directly with Delhi NCR's top JCI & NABH accredited hospitals and internationally acclaimed surgeons.

---

## 🌟 Key Features

- **Delhi Hospital Directory**: In-depth profiles of premier institutions including **Indraprastha Apollo, Max Super Speciality Saket, Fortis Escorts Heart Institute, Medanta - The Medicity, BLK-Max, Sir Ganga Ram Hospital, Manipal Hospital Dwarka, and FMRI**.
- **Renowned Specialists & Surgeons**: Profiles and credentials of legendary doctors like **Dr. Ashok Seth, Dr. Naresh Trehan, Dr. Arvinder Singh Soin, Dr. Harit Chaturvedi, Dr. S. K. S. Marya, Dr. Bipin Walia, Dr. Abha Majumdar, and Dr. Vinod Raina**.
- **Interactive Treatment Cost & Savings Calculator**: Live comparison between Delhi and the USA, UK, and UAE with multi-currency support (USD, EUR, AED, GBP, INR).
- **360° Free Patient Concierge**: 
  - Free multi-doctor second opinions within 24 hours.
  - Official Indian Medical Visa (e-Medical Visa) invitation letter facilitation.
  - Complimentary chauffeured airport pickup from Indira Gandhi International Airport (DEL).
  - Dedicated multilingual interpreters (Arabic, Russian, French, Bengali, Swahili).
  - Sanitized accommodations near hospital campuses & Halal dining arrangements.
  - 6-month post-discharge telemedicine support.
- **Smart Discovery Engine**: Live search and filter by medical condition, specialty, and Delhi region.
- **Interactive Modals & WhatsApp Desk**: Seamless booking flows, drag-and-drop report attachment simulation, and floating 24/7 support dock.

---

## 💻 Tech Stack & Design System

- **Frontend**: Pure HTML5 (Semantic & SEO Optimized) + Vanilla JavaScript (ES6+).
- **Design System**: Vanilla CSS with glassmorphic cards, custom color tokens, modern typography (`Plus Jakarta Sans` & `Outfit`), and responsive breakpoints.
- **Server**: Zero-dependency Node.js HTTP server.

---

## 🚀 Running Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Gurfatehbro/carebridge.git
   cd carebridge
   ```

2. **Start the local server:**
   ```bash
   node server.js
   ```

3. **Open in browser:**
   ```
   http://localhost:3000
   ```
